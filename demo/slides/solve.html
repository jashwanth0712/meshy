Three glyphs, one idea: access is a name. 01 Name. Read the chain bottom-up: claude-1.db1.prod.acme.eth. Every level is its own ENSv2 registry. The leaf is the grant: owned by the agent's address but registered with roleBitmap 0, so the agent can't renew or move it; it expires on its own (1 hour by default, the ring is the countdown); its meshy.policy record holds the folder rules sealed to the device's X25519 key and the org key, bound to the grant's token id. The agent itself joined as claude-1.agents.acme.eth only after a human approved it with World ID. 02 Sandbox. The outer box is the device, the dashed box is the granted folder, the spark is the agent. meshyd runs each session in bubblewrap plus GateFS (a policy-checking FUSE layer) on Linux, or Seatbelt on macOS. The agent reaches only granted folders, an optional command allowlist, or a single service port named in ENS. /etc/shadow, ../, symlinks out and the network all stop at the wall with MESHY_BLOCKED. 03 Revoke. An admin calls unregister() on Sepolia. meshyd re-checks every live grant on every block, so the session is killed in the block that carries the revocation, about 150 ms after the daemon sees it. The dashed line is the time the agent never got. If the chain view goes stale for 45 s, it fails closed. Bottom: every grant, block and kill lands on Arkiv, written by the device's own address, sealed to the org key, read-only.
