Then the map disappears

One mesh, no centre

Every named device reaches every other directly, over WireGuard.

Geography stops mattering. The map fades out and the six named devices pull together into one mesh. Every line is a direct WireGuard tunnel between two peers, so a laptop in Mumbai talks to a server in Dubai without hairpinning through a head office or a vendor's coordination server. The groupings are the ENS networks they belong to: mumbai.acme.eth, chennai.acme.eth, dubai.acme.eth and people.acme.eth. Staked providers relay traffic only when two peers can't reach each other directly. Honest status: the mesh layer is built on NetBird's userspace client but hasn't run on a live provider yet.
