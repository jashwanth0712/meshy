Five planes around one source of truth. Control (top, outlined in blue because everything reads it): ENSv2 on Sepolia. Every org, network, device, service, agent and grant is a name in its own UserRegistry. Native expiry is the grant lifetime; unregister() is revoke; grants are registered with roleBitmap 0 so the agent can't renew or move them; Enhanced Access Control gives delegated admins root roles on one network and a setter role for only meshy.policy; every agent gets its own PermissionedResolver where it may set only meshy.ssh. The arrows show ENS state flowing down: the agent CLI pins the device's SSH host key from meshy.ssh-host (no trust on first use), the provider's meshy-sync compiles NetBird groups, policies and DNS from ENS, and meshyd re-checks every live grant on every block with findExactOwner plus getState. Data path (middle): the agent (meshy CLI or the Claude Code MCP plugin, admitted only with a provider-signed World ID attestation) reaches the device over a WireGuard mesh built on NetBird's client/embed in userspace, run by staked providers. meshyd authorizes in three steps: Authenticate (key, addr, World ID), AuthorizeSession (live device grant plus a policy that decrypts and matches the token id) and AuthorizeService (a live service grant; meshyd dials only the ENS-declared target). The session runs inside the dashed sandbox: bubblewrap with GateFS, a policy-checking FUSE loopback, on Linux, and Seatbelt on macOS, down to the granted folder. If a grant dies, meshyd kills the session about 150 ms after it sees the block, and it fails closed if the chain view goes stale for 45 s. Bottom left: settlement on Sepolia. ProviderRegistry holds provider stake and lets anyone slash with an EIP-712 attestation checked against ENSv2 on-chain (ancestor dead, expired at issuance, or re-registered); 50% goes to the reporter. MeshySubscription charges USDC per seat into escrow, 95% to the provider and 5% to the treasury, with prorated refunds. Bottom right: Arkiv. meshyd batches three entity types, each with its own lifetime. Payloads are sealed to the org key, entities are read-only, and readers only trust entities whose $owner matches the device's addr record in ENS. Honest status: the NetBird mesh is built but has not yet run on a live provider (agents reach meshyd over TCP today), and the World ID attestation on the demo agent is a dev signature.
