Access is a name.

One folder. One hour. Then it’s gone.

claude-1 — meshy

$ meshy ssh db1.prod.acme.eth -- ls

q3.csv   q4.csv   board.pdf

$ cat /etc/shadow

MESHY_BLOCKED  outside grant

 

grant  claude-1.db1.prod.acme.eth

scope  /srv/reports : ro

ends   in 41 min

meshy

Access is a name. On the screen: an agent's whole permission, which is one ENS subname, claude-1.db1.prod.acme.eth. It can list the reports folder it was given, read-only. The moment it reaches for /etc/shadow it gets MESHY_BLOCKED. And the grant ends on its own in 41 minutes, because expiry is native to the name.
