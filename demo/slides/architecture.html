Everything orbits one source of truth. Centre: ENSv2 on Sepolia, the control plane. Every org, network, device, service, agent and grant is a name in its own UserRegistry; expiry is the grant lifetime, unregister() is revoke, roleBitmap 0 stops agents moving their grants, Enhanced Access Control gives delegated admins scoped roles, and every agent has its own PermissionedResolver. Dashed spokes: every component reads ENS. The agent CLI pins the device's host key from meshy.ssh-host, so there's no trust on first use. World ID: the provider runs the World ID Agent Pass device flow, validates the ID token server-side, and signs the attestation stored in meshy.worldid; meshyd refuses agents without it. Contracts: ProviderRegistry holds provider stake and anyone can slash with an EIP-712 attestation checked against ENS on-chain (ancestor dead, expired at issuance, re-registered); MeshySubscription charges USDC per seat into escrow, 95% to the provider. Arkiv: readers only trust audit entities whose $owner equals the device's addr record in ENS. meshyd: re-checks every live grant on every block and fails closed if the chain view is 45 s stale. The mesh: meshy-sync compiles NetBird groups, policies and DNS from ENS. Solid blue: traffic. The agent (meshy CLI or the Claude Code MCP plugin) reaches the device over a WireGuard mesh built on NetBird's client/embed in userspace and run by staked providers. meshyd authorizes in three steps (identity, device grant with sealed policy, service grant) and runs the session in the sandbox: bubblewrap plus GateFS on Linux, Seatbelt on macOS. Grey: meshyd writes sealed, read-only audit to Arkiv. Honest status: the NetBird mesh is built but hasn't run on a live provider yet (agents reach meshyd over TCP today), and the demo agent's World ID attestation is a dev signature.
