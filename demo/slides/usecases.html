Scope levels: folder (ro / rw) · command allowlist · one service port · whole network.

Six real-world cases, each one ENS name. A coding agent gets read-only access to /srv/reports on db1 for an hour: the default grant, which simply expires. An ML agent on a GPU rig gets models but not datasets; this is the exact lifecycle verified on Sepolia with rig1. A service grant like claude-1.camera.pi.home.acme.eth opens one port declared in the service's meshy.service record and never a shell; the e2e suite proves an on-chain revoke cuts a live stream. A policy can carry a command allowlist, so a backup agent can run only pg_dump with no shell and no shell metacharacters. In an incident, unregistering a whole network kills every grant under it, because the watcher's findExactOwner returns zero if any ancestor is dead. And with Enhanced Access Control, a managed-service provider can give each client an admin for one network who can grant and revoke there, write only meshy.policy, and has no rights on other networks or on meshy.orgkey; that is verified live on home.meshydemo.eth.
