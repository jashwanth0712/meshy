# demo/: the Meshy pitch presentation

The full presentation, with the live map scenes woven in, served by the web app at **`/demo`** (`web/public/demo.html`, wired by a rewrite in `web/next.config.ts`).

## Controls
→, Space or a click advances; ← goes back. Scene-to-scene steps animate both ways, and a press mid-animation finishes it or turns it around. N shows speaker notes, F goes full screen, Home and End jump to the ends, and `#slide-12` links straight to a slide.

## What's here
| Path | What |
|---|---|
| `slides/*.html` | The deck slides, one `<section>` each, exported from the Slides artifact. `map-*.html` are kept only for their speaker notes; the scenes replace them |
| `scene.js` | Canvas renderer for the 23 scenes: world map → India → pick and name → mesh → agents, people and a team → provider → ENS layer → billing → the ENSv2 chapter (zoom into acme.eth, its nodes morphing into the name tree, sealed grant, laptop enforcing routes, every device, revoke, laptop blocks it, zoom out) → Arkiv audit log → insights |
| `dots.json` | Land dots from Natural Earth (public domain), generated by `dots.mjs` with `world-atlas`, `topojson-client` and `d3-geo` |
| `present.template.html` | The player: stage, slide shims for `x-icon` and `x-connector`, navigation, notes |
| `assets/` | The two Twingate screenshots used on the "Before Meshy" slide |
| `render.cjs` | Renders scene frames with Playwright (used to make the deck's video clips) |
| `build.py` | Assembles everything into `web/public/demo.html` |

## Rebuild
```bash
python3 demo/build.py          # writes web/public/demo.html
```
Scene copy (headlines) and the order of slides and scenes are at the top of `build.py`.
